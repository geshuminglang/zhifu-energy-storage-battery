ZHIFU ENERGY STORAGE WEBSITE

Open index.html in a browser or upload the entire folder to a static web host.

Structure:
- index.html: home page
- products.html: product catalogue and filters
- products/*.html: individual system detail pages
- applications.html, about.html, contact.html
- assets/: styles, scripts and optimized supplied imagery

The quote form does not send data to a server. It prepares an email or WhatsApp
message in the visitor's own app. Replace the supplied company contact details
only if ZHIFU provides updated information.

Product specifications are based on the supplied Excel sheets. A few source
labels and values are inconsistent (for example, model names ending in "W" and
the integrated system's switch-time row containing percentages). They have been
reproduced without silent correction. Confirm final production specifications
before publishing.

Recommended before launch:
1. Connect the quote form to a form endpoint if server-side lead capture is needed.
2. Add the final production domain to canonical URLs and an XML sitemap.
3. Confirm claims, certifications, model names and data with the factory.
4. Optionally add local-language versions after the English source is approved.
